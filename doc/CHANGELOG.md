# 升级日志

## 5.2.0 — 2026-10-24

- 三套自适应布局：设置弹窗 / 宽屏整页 / 手机小屏
- 页头显示版本号，支持检查更新（npm 为主、GitHub 兜底）
- 连接行内只读开关
- 模型侧数据库访问策略段，可由用户关闭
- 新增发布测试矩阵与发版闸门
- 文档分层，新增文档一致性格门

## 5.1.0 — 2026-10-09

- 环境级只读（写操作由 dbhub 原生拒绝）
- 手动 SSH 隧道（密钥 / 密码，单跳 ProxyJump）
- 分层诊断：SSH 层 / 数据库层 / 插件层
- 独立的 SSH 层连通性测试
- 侧边栏入口随插件启用状态显隐
- 连接测试提速
- SSH 密钥路径支持默认值

## 5.0.1 — 2026-10-08

- 修复超时预算计时器不触发的问题

## 5.0.0 — 2026-10-08
