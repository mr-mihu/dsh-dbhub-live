# 升级日志

## 6.1.0 — 2026-11-17

- dsh-Go 手机端原生设置面板：状态、连接列表（点按测一次连通性）、启用/停用与刷新
- **手机端可直接改五项设置**（点一下即生效）：结果行数上限、并发测试数、自动更新间隔、侧边栏入口、注入访问策略。写入复用网页卡片那条唯一写路径（同一份值、同一套校验、同样落盘），被拒时手机会弹回宿主的真实值
- 面板只带元数据（无 DSN / 账号 / 口令 / 隧道身份）；增删改连接与密钥仍在网页版。**导出目录不在手机端**：它是自由文本且保存要实测目录可写，手机端只显示当前值
- 写路径收敛成 `commitOptionPatch`（`POST /options` 与手机面板共用），没有再出现第二条能跳过 `exportDir` 可写探针的入口
- 设置表单字段补齐中英双语描述，手机端原生表单显示「导出目录」而不是 `exportDir`
- 只用 dsh-Go 视图协议 v1 的组件（含 v1 的 `options` 单选），老版本 App 也画得出来；没有 dsh-Go 桥接的主机行为不变
